# 工作日志管理系统 - 使用说明

## 首次使用（本机 Windows 部署）

1. 构建前端：`cd frontend && npm install && npm run build`
2. 右键点击 `scripts/install-autostart.ps1` →「使用 PowerShell 运行」（需管理员，配置开机自启）
3. **首次启动会在服务器日志中打印访问密码**（只显示一次，务必保存）
4. 浏览器访问 <http://localhost:4173>，输入密码登录

> 云服务器 / NAS 部署（Docker、HTTPS、Tailscale）见 [deployment.md](deployment.md)。

## 登录与多设备

- 所有数据存在服务器上，任何设备（电脑/手机）用同一密码登录看到的都是同一份数据
- 登录状态保持 30 天；「系统设置 → 退出登录」只清除登录会话，不删除任何数据
- 修改密码：「系统设置 → 修改访问密码」（修改后其他设备需重新登录）
- 多设备同时编辑是安全的：数据按条目增量同步，不会互相覆盖

## 各页面功能

| 页面 | 说明 |
|---|---|
| 工作台 | 自然语言智能录入（自动识别日志/项目/待办/客户）、今日/本周关注、逾期提醒 |
| 日历 | 日志按日/周/月查看与统计；**搜索框支持跨全部日期的日志全文搜索**；AI 生成日报/周报/月报，可导出 `.md` 文件 |
| 项目 | 项目阶段管理、甘特图计划、进度自动同步 |
| 商机 | 线索→方案→投标→等结果→中标/落标 阶段看板；标书递交/开标/保证金关键日期倒计时，工作台自动提醒 7 天内截止；中标率统计 |
| 待办 | 看板/列表双视图、优先级筛选、批量操作、快速添加 |
| 客户 | 客户档案、联系人（负责人/经办人）、拜访记录、跟进状态 |

## 系统设置（左下角齿轮菜单）

| 菜单 | 说明 |
|---|---|
| AI 服务设置 | 配置 OpenAI 兼容供应商；API Key 只保存在服务器 |
| 导出数据 | 下载 JSON 备份（不含 API Key） |
| 导入数据 | 从 JSON 备份恢复（导入前服务器自动做一次备份） |
| 回收站 | 已删除的日志/待办/客户等保留 30 天，可恢复或彻底删除 |
| 数据备份 | 查看/下载服务器的自动备份文件（保留最近 14 份） |
| 清空数据 | 清除全部业务数据；**AI 配置与登录状态保留** |
| 修改访问密码 | 见上 |
| 退出登录 | 见上 |
| 主题切换（月亮/太阳图标） | 深色 / 浅色模式 |

## 本机 Windows 部署相关

| 脚本 | 用途 |
|---|---|
| `scripts/install-autostart.ps1` | 首次使用，配置开机自启 |
| `scripts/uninstall-autostart.ps1` | 取消开机自启并停止服务 |
| `scripts/start.ps1` | 手动启动（临时使用） |

## 注意事项

- 需要已安装 Node.js ≥ 24
- 数据存储在服务器 `data/worklog.sqlite`；自动备份在 `data/backups/`
- 忘记密码：删除服务器 `data/config.json` 后重启服务（重新生成密码），或在 Docker 中查看启动日志
